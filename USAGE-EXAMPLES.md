# Примеры использования / Usage Examples

## Базовая версия (hide-custom-commands.sk)

### Установка
1. Скопируйте файл в `plugins/Skript/scripts/`
2. Выполните `/skript reload hide-custom-commands`

### Что происходит
- Все игроки видят только ванильные команды при нажатии Tab
- Кастомные команды полностью скрыты из автодополнения
- Команды всё ещё можно использовать, просто ввести вручную

### Пример
```
До установки скрипта:
/hel[Tab] → /help, /healmenu, /helpop, /heal

После установки скрипта:
/hel[Tab] → /help (только ванильная команда)
```

## Расширенная версия (hide-custom-commands-advanced.sk)

### Установка
1. Скопируйте файл в `plugins/Skript/scripts/`
2. Выполните `/skript reload hide-custom-commands-advanced`
3. Настройте пермишены (опционально)

### Возможности
- Скрытие кастомных команд для обычных игроков
- Показ всех команд для администраторов с пермишеном
- Команда `/toggletab` для переключения режима

### Настройка пермишенов

#### LuckPerms
```bash
# Дать игроку возможность видеть все команды
/lp user <игрок> permission set tabcomplete.bypass true

# Дать группе возможность видеть все команды
/lp group admin permission set tabcomplete.bypass true

# Дать пермишен на команду /toggletab
/lp user <игрок> permission set tabcomplete.toggle true
```

#### PermissionsEx
```bash
# Для игрока
/pex user <игрок> add tabcomplete.bypass
/pex user <игрок> add tabcomplete.toggle

# Для группы
/pex group admin add tabcomplete.bypass
/pex group moderator add tabcomplete.toggle
```

### Команда /toggletab
Позволяет игроку переключать режим просмотра команд (требует пермишен `tabcomplete.toggle`)

```
/toggletab - Включить/выключить показ всех команд
```

### Пример использования
```
Обычный игрок:
/sk[Tab] → (ничего, команда скрыта)

Администратор с пермишеном:
/sk[Tab] → /skript, /skills, /skyblock (все команды видны)
```

## Настройка списка команд

### Добавление команды в список ванильных
Если вы хотите добавить свою команду в список "разрешенных":

1. Откройте файл скрипта
2. Найдите секцию `options:`
3. Добавьте команду в список `vanilla-commands`

```yaml
options:
    vanilla-commands: "help", "give", "gamemode", "mycommand"
```

### Удаление команды из списка
Просто удалите её из списка `vanilla-commands`

## Частые вопросы (FAQ)

### Команды всё ещё можно использовать?
Да! Скрипт только скрывает их из автодополнения. Вы можете написать команду вручную и она будет работать (если у вас есть пермишен).

### Работает ли это с плагинами?
Да, скрипт скрывает команды от любых плагинов, включая:
- EssentialsX
- WorldEdit
- CoreProtect
- Vault
- И т.д.

### Можно ли скрыть только определенные команды?
Да, вы можете инвертировать логику скрипта:
- Вместо белого списка (ванильные команды) создать черный список (команды для скрытия)
- Или добавить проверку на конкретные префиксы команд

### Влияет ли это на производительность?
Минимально. Скрипт работает только при нажатии Tab и обрабатывает небольшой список команд.

## Решение проблем

### Скрипт не работает
1. Проверьте версию Skript: `/skript info`
2. Убедитесь что скрипт загружен: `/skript list`
3. Проверьте ошибки: `/skript info hide-custom-commands`
4. Перезагрузите скрипт: `/skript reload hide-custom-commands`

### Некоторые команды не скрываются
- Убедитесь что команда не в списке ванильных
- Проверьте что у игрока нет пермишена `tabcomplete.bypass`

### Ошибки при загрузке
- Обновите Skript до версии 2.6 или выше
- Проверьте синтаксис если вы редактировали файл
- Убедитесь что файл в кодировке UTF-8
