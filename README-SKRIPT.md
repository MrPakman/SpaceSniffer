# Скрипт для скрытия кастомных команд из Tab автодополнения

## Описание

Этот скрипт для Skript плагина скрывает все не ванильные (кастомные) команды из автодополнения через Tab в Minecraft. Игроки смогут видеть и автодополнять только оригинальные команды Minecraft.

## Требования

- Minecraft Server (Spigot/Paper/Purpur)
- Плагин Skript версии 2.6 или выше
- Java Edition 1.16+

## Установка

1. Убедитесь, что у вас установлен плагин [Skript](https://github.com/SkriptLang/Skript)
2. Скопируйте файл `hide-custom-commands.sk` в папку `plugins/Skript/scripts/`
3. Выполните команду `/skript reload hide-custom-commands` или `/skript reload all`
4. Готово! Теперь кастомные команды скрыты из Tab автодополнения

## Как это работает

Скрипт перехватывает событие `tab complete` и фильтрует предложения автодополнения:
- Проверяет каждую команду из списка автодополнения
- Сравнивает её со списком ванильных команд Minecraft
- Оставляет только ванильные команды в списке
- Скрывает все плагиновые и кастомные команды

## Список ванильных команд

Скрипт содержит полный список ванильных команд Minecraft Java Edition включая:
- Административные команды (ban, kick, op, deop и т.д.)
- Игровые команды (gamemode, give, teleport и т.д.)
- Мировые команды (worldborder, setblock, fill и т.д.)
- Системные команды (save-all, stop, reload и т.д.)

## Настройка

Если вы хотите добавить или удалить команды из списка ванильных:

1. Откройте файл `hide-custom-commands.sk`
2. Найдите секцию `options:` в начале файла
3. Измените список в параметре `vanilla-commands`
4. Сохраните файл и перезагрузите скрипт

Пример:
```yaml
options:
    vanilla-commands: "help", "give", "teleport", "gamemode"
```

## Примечания

- Команды всё ещё можно использовать, они просто скрыты из автодополнения
- Это не влияет на права/пермишены команд
- Скрипт работает для всех игроков на сервере
- Для более точной настройки можно добавить проверку пермишенов игрока

## Возможные проблемы

**Команды всё ещё видны в Tab:**
- Проверьте что скрипт загружен: `/skript list`
- Убедитесь что нет ошибок: `/skript info hide-custom-commands`
- Попробуйте перезагрузить скрипт: `/skript reload hide-custom-commands`

**Некоторые ванильные команды не работают:**
- Убедитесь что список команд актуален для вашей версии Minecraft
- Проверьте версию Skript (должна быть 2.6+)
